# 幾何学メーカー — 第3.5段階（多様な構図と成長アニメーション）

シード連動配色と各色の再抽選・固定を追加しました。[操作・互換性](docs/SEEDED-COLORS.md)を参照してください。

PNG／SVG書き出し・設定JSON保存／読込・カスタム解像度に加え、配色の固定・個別再抽選、密度、成長アニメーションを実装しています。最新版は`2d-v5`です。[第3.5段階の操作・比較画像・検証](docs/diversity-v5/README.md)を参照してください。

React + TypeScript + Vite / SVG の、バックエンド不要のWebアプリです。
Windows・macOSのデスクトップブラウザで利用する構成です。

## 実装済み

1. シード入力（数値・文字列・日本語・絵文字・空文字）
2. 暗号学的乱数を用いたランダムシード生成
3. 単色と3色グラデーション背景の切り替え、任意色・方向の調整
4. 16:9 / 9:16 / 1:1 / 4:5 / 3:2 / 21:9 / A4縦 / A4横
5. 13種類の構図からシードで選び、1〜2個の主役と関連する図形群を背景／中景／前景に生成。六角形・同心円・格子・枝分かれ回路などを使い分け、余白にかかる補助図形は省く
6. SVGによるライブプレビュー
7. 同じシード・設定・アルゴリズム版での再生成

シード欄は選択・コピー・再入力できます。変更は即座に反映されます。「同じ設定で再生成」でも構図は変わりません。背景色と図形配色は独立し、色変更によって図形配置は変わりません。

## 開発・ビルド

Node.js 22.12以降（検証環境: Node.js 24.22.1、npm 11.9.0）を使用してください。

```sh
npm ci
npm run dev
```

表示されたローカルURLをブラウザで開いてください。

```sh
npm run typecheck
npm test
npm run build
npm run preview
```

`dist/` が静的公開用の成果物です。開発・プレビューサーバーは開発確認用で、アプリ自体にバックエンドは不要です。ファイルの直接ダブルクリックではなくHTTPサーバーで確認してください。実行時に外部フォント・CDN・APIを読み込みません。

## 再現性と構成

- `src/scene.ts`: バージョン付きPRNG、構図計画、連続ノイズ・密度場、3層の図形データ生成、比率定義
- `src/scene-v5.ts`: 新版の構図計画、図形ファミリー、密度付き最大候補生成
- `src/animation.ts` / `src/AnimationControls.tsx`: 決定的な成長順序と再生制御
- `src/geometry.ts`: 共通の図形輪郭、接続点、境界と余白の判定
- `src/paint.ts`: 指定背景の色を保ったまま、図形側のコントラストと発光を調整
- `src/Preview.tsx`: 図形データからSVGを描画
- `src/App.tsx`: 操作画面・設定状態
- `src/scene.test.ts`: 再現性・各比率・乱数などのユニットテスト
- `src/composition.test.ts`: 全8比率×100シードの役割・階層・接続・余白・画面端、構図タイプの多様性、v4固定ダイジェスト
- `src/refinement-v4.test.ts`: コーナー型の対重心、三角形面積、明るい背景の補正
- `src/paint.test.ts`: 明暗・有彩色背景の視認性、縦横比を考慮したグラデーション座標、限定した発光
- `tests/app.spec.ts`: 実ブラウザの操作・画像一致テスト

最新版は`2d-v5`です。生成アルゴリズム欄で旧`2d-v4`も選択できます。v4の設定JSONは旧版のまま復元し、自動的に新版へ置き換えません。v5を選んだ場合のみ新しい構図に切り替わります。保存JSONと画像ファイル名も現在の版を保持します。シードは文字列として扱い、`1` と `01`、前後空白も区別します。空文字も有効なシードです。PRNGは従来のFNV-1a + Mulberry32を維持。描画と再生成に `Math.random()` や時刻は使用せず、明示的なランダムボタンだけが `crypto.getRandomValues()` を使用します。再現時は同じシード、比率、背景種類・色・角度、アルゴリズム版を使用してください。ページを読み直すと設定は初期値に戻ります。背景色を変えても構図は変わらず、図形の明暗と発光だけが適応します。

SVGの座標と実寸の比率を一致させ、画面サイズ変更時も図形を縦横に引き伸ばしません。同一環境の再入力・再読み込みでは描画画像の一致も確認しています。異なるOS・ブラウザ間のピクセル単位の一致はフォントや描画系に依存し、今回の保証対象には含めません。

初回はリポジトリの **Settings → Pages → Build and deployment → Source → GitHub Actions** を設定してください。Actionsが無効ならSettings → Actions → Generalから有効にします。その後mainへのpush、またはActions → Deploy to GitHub Pages → Run workflowで実行できます。

公開先は `https://shugurerune.github.io/geometry-maker/` です。デプロイの完了はActionsの `Deploy to GitHub Pages` 実行結果で確認してください。完了後、iPhoneのSafariで同じURLを開けます。Safariで表示されない場合は、末尾の `/` まで含めてURLを確認し、再読み込みしてください。iPhone実機の操作確認は別途必要です。

## 今回の対象外

図形個別編集、3D/Three.js、MP4・WebM、Blender、PSD、待機画面は対象外です。

### 図形密度

縦横比の下のスライダーで0〜100%（5%刻み）を調整できます。初期値50%は現在のアルゴリズムの標準、0%は背景のみです。主役の位置を保ち、補助図形・装飾の量を変更します。PNG/SVGと設定JSONにも密度を反映します。旧JSONは50%として読み込みます。[方式・比較画像・検証結果](docs/density/README.md)を参照してください。

### 成長アニメーション（第3段階）

生成設定で有効化し「最初から再生」を押してください。再生／一時停止、タイムライン、成長時間、再生速度、5種類のイージングに対応します。PNG/SVGは常に完成状態を保存し、JSONはアニメーション設定も保存します。[操作・実装・検証画像](docs/growth/README.md)。

### 多様性と再生成（第3.5段階）

v5では追加16種類の図形と13種類の構図を組み合わせます。アニメーション有効時は「同じ設定で再生成」「ランダムシード」、手動シードのEnter／フォーカス移動による確定で、先頭から再生します。同じ設定で再生成しても構図・色・順序は変わりません。色・密度の変更は再生位置を維持します。視覚効果軽減時は再生成の自動再生を控え、完成状態を表示します。明示的な再生ボタンは利用できます。

比較画像を含む[第3.5段階の報告](docs/diversity-v5/README.md)を参照してください。全ブラウザテストは開発サーバーで実行してください（新図形のテスト専用ページは本番ビルドには含めません）。

### 暗色テーマと発光

配色欄の「ミッドナイト」「ネオンナイト」で固定していない色を暗色向けへ変更できます。「発光強度」は0〜100%、初期値0%。配置や再生位置を維持して即時反映し、PNG/SVG・設定JSONにも保存します。[比較画像・使用方法・検証](docs/glow/README.md)。

### 初期設定とUIテーマ

ページを開くたびに暗号学的乱数でシードを生成します。初期発光は100%（調整範囲0〜200%）、成長アニメーションはONで先頭から自動再生します。視覚効果軽減時は自動再生を控えます。ヘッダーのUIテーマ切り替えは生成画像を変更せず、選択をブラウザに保存します。保存できない環境でも切り替え自体は利用できます。旧JSONでアニメーションや発光指定がない場合は従来の無効／0%で復元します。

動画保存は「保存・再利用」→「動画書き出し」から利用できます。WebM / 対応環境のMP4、解像度、24・30・60fpsに対応します。使用方法・ブラウザ制約は[第4段階の動画書き出し](docs/stage4-video/README.md)を参照してください。

プレビューとPNG・SVG・MP4・WebMの線幅・発光はSVG座標を基準に共通化しています。[描画品質の原因調査・比較画像・検証結果](docs/render-quality/README.md)を参照してください。

第5段階の自動待機画面は生成設定からONにできます。[操作方法・ループ仕様・動画保存・検証上の制限](docs/ambient/README.md)を参照してください。

### 6カテゴリーの設定画面（第5.5段階）

「図形」「背景」「カラー」「装飾」「アニメーション」「書き出し」から設定を選びます。初期表示は図形で、選択中のボタンを再度押すと閉じます。背景色の編集はカラー、線の太さと発光は装飾、成長再生と自動待機画面はアニメーション、画像・動画・JSON保存は書き出しにまとめています。切り替えても設定や再生位置、進行中の書き出しは維持されます。[配置・操作方法・PC／スマホ表示例](docs/ui-renewal/README.md)。
