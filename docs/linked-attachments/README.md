# 連結多角形の装飾と枝の根元

連結図形の最初の輪郭（六角形）だけを使っていた配置元を、六角形・五角形の両方へ拡張しました。枝と小装飾を左右交互に選び、それぞれの多角形の頂点平均から求めた中心を基準に外向きの方向を計算します。密度の表示開始条件も左右で偏らないようにしています。

頂点数より多い枝候補を選んで同じ頂点を繰り返す処理を修正しました。さらに、採用済みの枝の根元との距離を確認し、同一地点や非常に近い根元（短辺の1.5%未満）の重複生成を抑制します。

seed `undefined-heartbeat`、16:9、密度100%、発光100%で比較：

- [変更後](after.png)

200シード×3比率で、連結図形の両側に枝が存在すること、各多角形の中心から外へ向くこと、枝の根元が重複しないことを検証。型チェック・ビルド・ユニット115件・既存ブラウザ20件が成功し、表示開始密度の調整後も密度・成長の3テストを再確認しました。
