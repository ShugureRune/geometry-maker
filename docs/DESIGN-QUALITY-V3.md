## 参考画像の分析と採用した特徴

2枚には、明暗の背景に共通する構図上の特徴があります。

| 参考画像の特徴 | v3での対応 |
| --- | --- |
| 大きなひし形・多重枠が視線を集め、小図形との重要度が異なる | 1〜2個の主役を先に設計。多重枠、円弧、三角形を使用し、明るい縁を限定的に重ねる |
| 長い斜めの帯・平行線が画面全体の流れを作る | 共通の方向と原点を持つ2本の流れに、太い半透明の面・細い帯・ガイド線を配置 |
| 紫・ミントの半透明面が重なり、奥と手前の差がある | 背景／中景／前景を明示し、線幅・不透明度・塗り・描画順を分ける |
| ドットや小三角は規則的なまとまりとして置かれる | 6列×3行のドット群、短冊の反復、三角群、円弧に沿う点・小円を使用 |
| 大きな図形は画面外まで続き、背景の広がりがある | コーナーの主役・帯・遠景円弧など、意図した図形だけ画面外への継続を許可 |
| 白系では細い紫の輪郭、暗色系では白やミントの光が効く | 指定背景を変更せず、図形のインク色を背景の明るさに適応。暗色系の発光は1〜2個のアクセントに限定 |

画像そのものの複製ではなく、これらの配置規則をシードから組み立てています。

## 変更前後の違い

v2は整理された一方で、主役が常に5個、図形数が常に76、中央に固定の禁止領域があり、小図形を独立に配置していました。

v3は、構図タイプ・主方向・主役・平行な流れ・密度場・読みやすい領域を先に計画します。背景の面やガイド、中景の主役と接続線、前景のアクセントを順に生成し、条件に合わない小図形は省きます。目標数に達するまで余白を埋める処理はありません。

| 項目 | v2 | v3 |
| --- | --- | --- |
| 主役 | 5個 | 1〜2個 |
| 構図 | 主方向と密集域、中央を固定で空ける | 5タイプ＋タイプ内の位置・方向・種類・サイズ・組み合わせの変化 |
| 階層 | 主役・補助・装飾を主にサイズで区別 | 意味上の役割と、背景・中景・前景の深度を分離 |
| 配置 | 密度付きの独立候補探索 | 主役の輪郭・頂点、平行な流れ、共有ノイズに沿ったグループ生成 |
| 余白 | 中央の30%×30%を一律保護 | 主役内部や非対称構図の疎な側に、その構図の読みやすい領域を予約 |
| 接続 | 主役への短い回路線 | 頂点からの回路線、分岐、円弧周辺の規則配置、平行な帯と短冊 |
| 端 | すべて画面内 | 主役の通常配置は余裕を持って画面内。コーナー・帯などは意図して画面外へ継続 |
| 配色・発光 | 背景に関係なく明るい色、主役5個に発光 | 図形側の明暗を背景へ適応し、発光は前景の限定した輪郭だけ |

連続ノイズと密度場は維持しています。近隣の帯の長さや密度には同じ空間ノイズを使い、装飾は主役の近傍を優先します。すべてを接続するのではなく、構図に必要なまとまりを残しています。

## 変更範囲と再現性

- `src/scene.ts`: 既存PRNG・連続ノイズ・比率定義を再利用し、5タイプの設計と関連する図形群を生成。版を `2d-v3` に更新。
- `src/geometry.ts`: SVGと空間判定で輪郭を共有。大きな枠の中の空洞を、塗りつぶされた図形と区別して扱う。
- `src/paint.ts`: 指定背景をサンプリングして図形のインク色を調整。背景の設定値を変更しない。
- `src/Preview.tsx`: 従来のSVGライブプレビューを維持し、共通輪郭と3層・適応する色・少数の発光を描画。
- `src/App.tsx`: 固定の「76 SHAPES」を実数表示へ変更した1行のみ。入力・設定項目・レイアウト・CSSは維持。
- 依存パッケージ、Vite設定、GitHub Actions、Pages設定は変更なし。

同じシード・比率・背景設定・アルゴリズム版で同じ構図・描画を再生成します。生成・描画中に `Math.random()` や現在時刻は使いません。ランダムボタンだけが従来どおり `crypto.getRandomValues()` を使います。背景変更は輪郭の明暗と発光に反映し、配置には影響しません。

v2とv3は同じシードでも結果が変わります。旧版はmainとコミット `407e581` に保持し、新しい設定保存や旧版切替UIは追加していません。

## 比較の再作成

Node.js 24を使用し、別ターミナルで `npm run dev` を起動します。テスト用Chromiumを用意してから実行してください。

```sh
CHROMIUM_PATH=/usr/bin/chromium node scripts/capture-design-quality.mjs
```

`CHROMIUM_PATH` は環境に合わせて変更・省略可能です。`BASELINE_URL`（既定: 現在のPages）と `PREVIEW_URL`（既定: localhost:5173）で比較先を指定できます。比較元が2d-v2、比較先が2d-v3でなければ撮影を停止します。将来mainが更新された場合は、旧コミットを別途起動して比較元を指定してください。`SHEETS_ONLY=1` は撮影済み画像から一覧だけを再作成します。これらは開発用スクリプトで、製品のPNG/SVG保存機能ではありません。
