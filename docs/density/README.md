# 図形密度（v4構図の拡張）

「縦横比」の下にある「図形密度」を操作します。0〜100%、5%刻み、初期値50%。操作中にプレビューへ反映されます。0%は背景のみ、25%は主役とその輪郭、50%は従来v4と同じ図形量、75〜100%は主役の周囲に補助線と装飾を追加します。色・シード・固定状態は変更しません。

PNG/SVGには表示中の密度が反映されます。「設定JSONを保存」で`density`も保存され、読込時に復元します。旧JSONで省略されている場合は50%。範囲外・整数以外の値は読込エラーになります。

## 方式と負荷

既存`2d-v4`の構図生成は変更せず、`src/density.ts`で独立した`density-v1`乱数列から最大密度の候補を生成します。候補はID、種類・位置・寸法、グループ、親ID、重要度、表示開始密度を持ちます。主役は1%以上で表示し、子の開始密度は親以上にします。追加候補は主役の輪郭付近と既存の空間密度マップに従い、余白・画面外・塗りつぶされた主役との衝突を除外します。追加は最大48図形、各主役につき最大100試行に制限しています。

候補生成はシード・縦横比の変更時だけ行い、スライダーでは表示対象の抽出だけ行います。既存図形の座標・寸法・描画順は変えません。色用の乱数列も消費しません。基本アルゴリズム版は`2d-v4`を維持し、密度拡張の乱数名前空間を`density-v1`で区別します。50%で以前の保存設定と同じ描画を維持します。

実ブラウザで2シード×3縦横比×5密度の30枚を作成し、比較画像を目視確認しました。

主役の三角形・円弧の位置と大きさを維持し、密度を上げた場合にもタイトル用の余白は残っています。追加要素は主役の周辺にまとまり、全面を均等に埋めません。図形数はSVG内のグループ数で、点群や多重枠も1図形として数えます。増加量は構図・余白・衝突条件によって異なり、密度に比例する図形数は保証しません。

## 検証

- ユニットテスト：6シード×対応全8比率。50%の従来v4との完全な形状一致、0%の空配列、単調な追加、親子関係、主役維持、決定性、ID重複なし、候補数上限、追加候補と余白の非交差。
- ブラウザ：16:9・9:16・1:1、幅1440px・390px、密度往復時の全SVG属性一致、色の維持、ドラッグ中の更新、キーボードとタッチ操作。
- 密度75%でPNG・SVG・プレビューの画素一致、JSON読込で密度と画像の完全復元。旧JSONの50%補完と不正値の拒否も検証。
- 型チェック・ユニットテスト78件・ビルド・ブラウザテスト11件がすべて成功。スマートフォンはChromiumのタッチエミュレーションで確認し、実機Safariでは未確認です。
