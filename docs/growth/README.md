# 第3段階：2D成長アニメーション

生成設定の「成長アニメーション」で有効化し、再生または「最初から再生」を押します。初期状態は静止画で、自動再生しません。視覚効果軽減を指定した環境でも意図せず動き出さず、点滅やフラッシュを使いません。

成長時間1〜30秒、速度0.25〜4倍、5種のイージングに対応。タイムラインは任意時刻を表示し、一時停止・再開・完成状態表示ができます。時間変更は現在の進行率を保ちます。シードや密度を変更しても再生位置は維持します。設定読込は先頭で停止します。

`animation.ts`は`growth-v1:seed:shapeID`から正規化時刻の出現スケジュールを生成し、絶対進行率から各図形の状態を計算します。親の成長後に子が始まり、主役→補助→装飾の順で出現します。全密度の候補から一度スケジュールを生成するため、色・密度変更で共通する図形の時刻は変わりません。フレーム内で乱数を生成しません。

線・三角形・ひし形・帯は輪郭の経路長を使って描画し、塗りを徐々に形成します。円弧は始点から描画し、円・ドットは中心から拡大します。点群は個々の点を時間差で表示します。主役には長い成長時間を割り当てています。requestAnimationFrameのタイムスタンプ差分を積算するため、フレームレートに依存しません。再生中以外はフレーム処理を停止します。

PNG/SVGは再生用DOMを使わず、完成状態の同じPreviewを独立してシリアライズします。途中停止中にも欠けません。JSONにはanimationEnabled / animationDuration / playbackSpeed / easingTypeを保存します。旧JSONはアニメーション無効・8秒・1倍・Ease In Outとして動作します。図形アルゴリズム2d-v4は維持しています。
