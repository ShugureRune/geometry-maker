# 第5.5段階：設定UIの整理

設定を次の6カテゴリーに分類しました。初期表示は「図形」です。同じボタンを再度押すと閉じ、別のボタンを押すと切り替わります。

| カテゴリー | 設定 |
| --- | --- |
| 図形 | シード、ランダム、再生成、クラシック／拡張モード、縦横比、密度 |
| 背景 | 単色／グラデーション、グラデーション方向 |
| カラー | 背景・図形の色編集、個別ランダム・固定、シード連動配色、暗色プリセット |
| 装飾 | 発光ON/OFF、発光強度、線の太さ |
| アニメーション | 成長再生・タイムライン、自動待機画面と既存の詳細設定 |
| 書き出し | PNG/SVG、MP4/WebM、解像度・FPS・時間、設定JSON、進捗・キャンセル |

カテゴリーの開閉状態だけを独立して管理し、パネルを非表示にしてもコンポーネントを破棄しません。設定値、カラー固定、再生位置、書き出し処理は保持されます。生成アルゴリズム、描画・書き出しエンジン、設定JSONの形式は変更していません。

PCでは左側に設定、右側に追従するプレビューを配置。スマホではプレビューの下に3列×2行のカテゴリーを配置しています。ボタンはキーボードで操作でき、開閉を`aria-expanded`で通知します。表示切り替えの軽いアニメーションは視覚効果軽減設定に従います。

## 確認

- 型チェック、ユニットテスト127件、ビルド。
- ブラウザで6カテゴリーの配置と切り替え、入力・固定状態の保持、一時停止位置、自動待機画面、書き出し途中の切り替えを確認。
- 390px、720px、1440pxでレイアウトと横はみ出しを確認。
- 既存の生成・配色・発光・アニメーション・PNG/SVG/動画・JSONの回帰テスト。
