# 無限スクロール：専用密度と背景連動カラー

## 操作

「アニメーション」→「自動待機画面を有効化」→「無限スクロール」で、次の設定が表示されます。

| 設定 | 範囲・初期値 | 動作 |
| --- | --- | --- |
| スクロール専用図形密度 | 0〜100%、5%刻み、初期80% | 各模様の主役を保ち、補助・装飾量を調整。0%は背景のみ |
| 背景色を自動変更 | 初期OFF | 単色／グラデーション背景を決定的に生成して滑らかに切り替える |
| 背景色変更間隔 | 3〜60秒、初期12秒 | 新しい配色へ移る間隔 |
| 背景に合わせて図形色を自動生成 | 初期ON | 実際の背景色から主役・補助・アクセント色を生成 |

自動配色中に特定の編集色を使うには、その色を固定するか、図形色の自動生成をOFFにしてください。

通常の「図形密度」とは独立しています。通常モードのカラー設定も変更しません。各カラーの固定はそのまま尊重します。図形色の自動生成だけを使うこともできます。

背景自動変更をOFFにすると、その時点の背景色を保持します。変更間隔を変えた場合も、現在の背景から次の変化を始めます。カラー編集で元の背景色を変更した場合は、編集した色を優先します。

既存の「トランジション時間」を背景の補間時間にも使用します。間隔の45%を上限とし、変化と保持を分けます。完全ループでは背景色も有限周期で元へ戻すため、変化間隔をループ時間に合わせて調整します。

## 配置・配色の方式

スクロール空間の配置をv2に更新し、チャンク間隔を従来の短辺1.25倍から1倍へ詰めました。各グループの大きさは従来に近づけながら、すべての主役の外接矩形の四隅がアンカーからチャンク幅の40%以内に収まるよう制限しています。アンカーの揺らぎを含めても隣接する主役の範囲に余裕を残します。

v4/v5の生成器・密度候補・成長スケジュールは再利用します。座標シードの名前空間は`scroll-world-v1`のまま維持し、同じチャンクの元の構図を引き継ぎます。密度・配色変更でアンカー、形状、成長時刻を動かしません。

背景色は元のシードと変更回数から計算します。初期背景の明暗傾向を保ちながら色相・彩度・明度を変えるため、暗い背景から明るい背景への突然の反転を避けています。明色設定から始めれば明色系の変化になります。

時間方向にはOKLCH色空間の短い色相経路で補間し、sRGBの範囲へ彩度を調整します。背景連動の図形色は背景の色相と明度を基準に3役の色を生成し、グラデーションの停止色・中間色を含むコントラストを評価します。無彩色に近い背景ではシード由来の方向を補い、不安定な色相変化を抑えます。

固定色は補正しません。極端な明暗が混在する固定グラデーションなど、1つの共通図形色では全位置のコントラストを同時に確保できない場合は、固定色を優先して最も見やすい候補を選びます。

## 性能・時刻指定描画

- 親グループの1つの変換でカメラ移動を適用し、図形の接続を維持します。
- 先読みと最大48件のLRUキャッシュを維持。完全に画面外へ出た模様のSVGは取り除きます。
- 固定の図形色に不要なSVGグラデーションを省き、完成済みの輪郭と背景に依存しない外接矩形を再利用します。
- 低負荷表示20fps、非表示タブの休止、視覚効果軽減の設定を維持します。
- MP4/WebMはプレビューと同じ時刻指定の背景・図形色・成長・チャンク処理を使います。
- PNG/SVGは従来どおり通常生成の完成静止画を保存します。

同じ密度100%・背景自動変更ON条件で、各方式140フレームの事前実行後に、React描画・DOM反映の処理時間を120フレーム×2回ずつ測定しました（GPUの描画時間は含みません）。開発用Chromiumでの平均は個別移動18.7ms／親グループ18.8ms、p95の2回平均は46.8ms／44.7msでした。平均はほぼ同等ですが、p95と変換更新箇所の少なさから親グループ方式を採用しました。同時刻画像の平均RGB差はv4で0、v5で約0.00005（各チャンネル0〜255）で、0.01未満の許容範囲で視覚的に一致しています。[実測値](camera-benchmark.json)。端末や描画条件によって処理時間は異なります。

## JSON

`ambient`内に`scrollDensity`、`scrollBackgroundAuto`、`scrollBackgroundInterval`、`scrollAutoFigureColors`を保存します。OFFで保持している背景は`scrollFrozen`へ保存します。旧JSONで項目がない場合は上表の初期値を補完します。

JSONは設定からの再生を復元します。通常モードの背景色・固定状態は維持され、途中で停止した背景色も保存されます。実行中に切り替えた背景の開始時刻は動画用スナップショットへ渡し、変更後のセッションと一致する時刻描画に使います。現在の設定で先頭から動画を作る場合は、待機画面を停止してから書き出してください。
