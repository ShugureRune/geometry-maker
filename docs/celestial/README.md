# 3D天体（恒星・惑星・リング・衛星・ブラックホール・中性子星）

「3Dモード」→「図形」→「天体（6種類）」からONにします。「天体のみ表示」で既存13種類の図形を隠し、天体6種類をまとめて表示できます。「図形＋天体」で両方を表示します。天体は個別にON/OFFできます。

- 恒星：光る球体とコロナ。高品質では周囲を照らす点光源も追加
- 惑星：反射光で見える青い地表。自らは発光しません
- リング付き惑星：帯状模様と、傾いた多重リング
- 衛星：クレーター模様、惑星本体の直径の **1/4**
- ブラックホール：黒い中心、光子リング、円盤、湾曲した光の弧を用いた**疑似重力レンズ**。正確な時空のレイトレーシング／背後の背景を物理的に屈折させる処理ではありません
- 中性子星：青白い球体と両極方向の2本のビーム。3Dアニメーション時計に合わせて通常の惑星より高速に回転

主要5天体は直径が近く、シードに応じてわずかに変わります。衛星のみ小さくなります。天体の位置・見た目は独立した決定的な乱数で計算し、既存の `3d-v1` 図形の配置・種類・シードの結果は変更しません。3D図形密度0%では天体も非表示になります。その他の密度設定では選択した天体をすべて表示します。

通常の3D再生・一時停止と回転量に従います。出現・消失設定が有効なときは、光の輪やビームもまとめて出し入れします。スマホ軽量モードではテクスチャや曲面の分割数を減らします。3D PNG出力と、3D専用設定JSONの保存・復元に対応します。旧JSONでは天体をOFFとして復元するため、従来の画像は変わりません。

検証：`src/three/celestial.test.ts`（再現性・相対サイズ・旧JSON）と `tests/celestial.spec.ts`（実ブラウザの描画・PNG・JSON・2D復帰）。
