# Geometry Maker 3D — 8種類のプロシージャル背景

3Dモードの **背景 → 3D空間の背景（8種類）** で背景を選択できます。既存の2D背景とは独立しており、従来の単色・グラデーションもそのまま残っています。

| 設定値 | 表示名 | 見た目・実装 |
|---|---|---|
| `starfield` | 無限の星空 | 360°の星の空＋複数の奥行きに浮かぶ3D星粒 |
| `galaxy` | 銀河 | 渦巻きの腕・明るい核・色分けした3D星粒 |
| `aurora` | オーロラ | ゆっくり揺れる緑紫の光のカーテン |
| `deep-sea` | 深海 | 青い水中の光の柱、揺れる光の模様、浮遊粒子 |
| `nebula` | 星雲 | 複数のノイズを重ねた紫・青・桃色の雲 |
| `cyber-tunnel` | サイバートンネル | 実体のある3Dネオンフレームと前進する廊下 |
| `retrowave` | レトロウェーブ | 縞模様の夕日、紫の空と遠近法の床グリッド |
| `digital` | デジタル空間 | 下方向に流れる文字風の緑の光のパターンと粒子 |

従来背景 `classic` は初期値です。

## 調節

- **背景エフェクトの強さ**：0〜200%。背景の光・粒子の明るさを調整。
- **星・粒子・模様の密度**：0〜200%。粒子数と模様の量を調整。
- **背景が動く速さ**：0〜300%。100%で通常速度。0%で静止。
- 3Dの再生／一時停止と背景の動きは同期します。
- 自動品質では、スマホは粒子数や球面の分割数を減らした軽量版に切り替わります。

## 既存機能との両立

- 13種類の3D図形、6種類の天体、ネオンネットワーク、通常の床グリッドと併用できます。
- レトロウェーブの内蔵床グリッドは、従来の3D床グリッドがONのとき二重表示を避けるため自動で非表示になります。
- 図形や天体のシードによる抽選は変わりません。背景の模様はシードに対して決定的です。
- 3D PNGには現在のカメラと背景の状態が含まれます。
- 3D設定JSONの `settings.sky` に種類／強さ／密度／速度を保存・復元します。以前のJSONにはこの項目が無くても、従来の背景を初期値として読み込めます。2Dプロジェクトの読み込みや表示は変更しません。
- 外部画像、サービス、API通信、音源、モデルファイルのダウンロードは使いません。

## 描画に関する注記

背景はシェーダー描画による演出です。銀河・星雲・オーロラ・水中・文字列の見た目は**軽量な視覚的近似**であり、天体物理の厳密なシミュレーションや実際の文字フォント表示ではありません。星粒やトンネル・床は3D座標を持ち、カメラ移動で見た目が変わります。

## 回帰チェック

- `npm test` / `npm run build`：パラメータ検証、シード再現性、旧3D JSONの互換性
- `npx playwright test tests/three-sky.spec.ts`：全8種類のPNG差分、従来背景への復帰、2D復帰、再生停止・JSON保存と復元、モバイル低品質での天体共存
- 既存 `tests/three.spec.ts` `tests/celestial.spec.ts` `tests/neon-network.spec.ts` `tests/three-spacing.spec.ts` を継続実行
