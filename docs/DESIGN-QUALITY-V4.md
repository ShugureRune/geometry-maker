# v4：v3の構図を維持したバランス調整

開発ブランチ `feat/2d-design-quality-v4`。基準は `feat/2d-design-quality-v3` の `88e364e`。同じソースを持つ公開main `b9fbccc` を比較撮影に使用しました。**mainへのマージ・Pages本番更新は行っていません。**

## 変更内容

- 構図タイプと乱数系列はv3のものを維持し、版だけを `2d-v4` として区別。シードによって別の構図へ入れ替わる変更を避けました。既存の5タイプ・PRNG・密度場・3層・図形輪郭・接続点計算を再利用しています。
- コーナー型は主役を少し内側へ移し、対角側に弱い副主役の円弧を設計。画面全体を均一に埋めず、タイトル用の予約領域を残したまま重心を釣り合わせます。
- 塗り面を持つ三角形に限って、面積を画面の8%以内に制限。非対称型の半径上限と塗りの濃さも調整し、線主体の大きなフレームは一律に縮めていません。
- 副主役の不透明度を主役より下げ、重要度の差を明確化。塗りの主役に重なる小装飾は省きます。
- 帯の長さを共有ノイズから決める方式を維持しつつ、隣接する帯が不要に重ならない幅へ調整。間隔と繰り返しの読みやすさを改善しました。
- 明るい背景では中景・前景のインク不透明度を必要に応じて上げ、遠景の薄さは維持。ユーザーの入力した色・角度、既存パレットは変更しません。
- 補助線・装飾にSVGの `non-scaling-stroke` を適用し、プレビュー縮小で細線が消える問題を軽減。主役と発光輪郭は従来の相対線幅を維持します。ぼかしの追加・拡大はありません。

変更は生成処理・描画補正の局所調整です。UI、CSS、依存パッケージ、Vite設定、GitHub Actionsは変更していません。3D、アニメーション、画像・動画出力などは追加していません。

## 実画像による評価

| 観点 | 観察結果 |
| --- | --- |
| 主役の明確さ | undefined-heartbeatでは三角形が小さく淡くなり、背後の帯と補助線が読みやすくなりました。主役の位置・方向は維持しています。 |
| 余白の自然さ | neon-cityは対角の円弧で片寄りを和らげ、中央のタイトルスペースを維持。右下全域を小図形で埋める処理はありません。 |
| 図形同士の関連性 | 頂点に接する回路線、円弧に沿う点・小円、平行な帯を維持。三角形の大きさを変えても同じ輪郭から接続を計算するため端点がずれません。 |
| コントラスト | 明るい背景で細い回路線・短冊・小装飾が見分けやすくなりました。背景そのものの色は同じです。 |
| 奥行き | 遠景を強くせず、中景・前景だけを補正。副主役の濃さと三角形の塗りを抑え、発光も限定したままです。 |
| 多様性 | 5タイプとタイプ内のシード差を維持。追加のランダム例でも斜め流動型・中央集中型を確認しました。 |
| 全体の完成度 | v3の図形言語を保ち、極端な重心・面積・細線を調整。コーナー型の広い余白は意図として残しています。最終的な色の強さや余白量は比較画像で確認できます。 |

占有率だけを美しさの点数として使っていません。新旧の明暗比較と3比率一覧を目視し、追加の21:9・A4でも主役の形状と切断を確認しました。三角形は従来と同じ正三角形、円弧は円として描き、キャンバス比率で形を引き伸ばしていません。

## 検証

- ユニットテスト **49件成功**。従来40件を維持し、全8比率でのコーナー型の対重心・主役と副主役の強弱・三角形面積、明るい背景の補正と入力色の不変性を追加検証。
- 既存の全8比率×100シードの構図検証も成功。有限座標、画面内／意図したはみ出し、予約余白、3層、回路端点、シード再現性、空間ノイズ、版別ダイジェストを確認。
- `npm run build` **成功**（TypeScript型チェックを含む）。
- Chromiumブラウザテスト **4件成功**。既存操作・全比率・再生成とリロードの画像一致、明暗と混在グラデーション、スマホ幅とタッチ操作を確認。
- 比較撮影72枚：JavaScript例外なし。新版36例の予約したタイトル領域への図形侵入は、実描画で0%。測定方法はv3と同じRGB差8以上・3px間隔で、各構図の予約領域を比較しています。

v4ではv3の構図系列を継承するため、v3固定ダイジェストはv4の新しい基準へ明示的に更新しました。既存のPRNG固定値は変更していません。入力・描画で非決定的な乱数や時刻を追加していません。

Safari実機は未確認です。スマホの動作確認はChromiumの画面幅・タッチ設定で実施しています。

## 再撮影

Node.js 24で `npm run dev` を起動後、`CHROMIUM_PATH=/usr/bin/chromium node scripts/capture-design-quality-v4.mjs` を実行できます。比較元は公開v3、比較先はlocalhostのv4です。将来公開版が変わったら `BASELINE_URL` にv3のローカルURLを指定してください。これらは開発用撮影処理で、アプリへのPNG保存機能追加ではありません。

mainとPages本番は、見た目の確認と指示があるまで更新しません。
