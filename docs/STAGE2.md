# 第2段階：保存と再利用

基準：`feat/2d-design-quality-v4` / `b774dcd`。開発ブランチ：`feat/stage2-export-settings`。main／GitHub Pages本番は変更していません。

## 実装済み

- 現在のSVGプレビューをPNG・単独のSVGファイルへ保存。
- シード・アルゴリズム版・全背景設定・比率・書き出しサイズを設定JSONへ保存／読込。
- 5解像度プリセットとカスタム幅・高さ。
- 入力エラー・読込エラー・保存中の操作制御と、44px以上の保存ボタン。

既存の生成コード・PRNG・配色計算・SVG描画は変更していません。追加パッケージ・CDN・バックエンドは不要です。PNGはブラウザのImage / Canvas / toBlob、SVGとJSONはBlobでダウンロードします。

## 起動

Node.js 22.12以降（検証は24）で、プロジェクト内から実行します。

```sh
npm ci
npm run dev
```

表示されたURLをブラウザで開きます。本番ビルドは `npm run build`、ビルド結果のローカル確認は `npm run preview` です。画像ファイルの生成処理自体はブラウザ内で完結し、サーバーへ送信しません。GitHub Pages用の既存相対アセット設定も維持しています。

## PNG・SVGの書き出し

1. 既存のシード、背景、縦横比で構図を作成。
2. プレビュー下の「保存・再利用」で解像度を選ぶ。
3. 「PNGを書き出す」または「SVGを書き出す」を押す。

プリセットは1280×720、1920×1080、1080×1920、1080×1350、2048×2048。プリセットを選ぶと、対応する構図の比率（16:9、9:16、4:5、1:1）も選択され、変更後の構図をプレビューで確認できます。

カスタムは各辺256〜8192pxの整数です。幅・高さを直接変更できます。カスタムサイズと構図の比率が異なる場合、構図を中央に収めて余白を追加します。引き伸ばし・切り取り・再生成はしません。余白は単色背景なら指定色、グラデーションなら先頭の色です。構図内のグラデーションは保持するため、余白と構図の境界で色がつながらない場合があります。画面にも余白追加を明記しています。同じ比率にすれば余白は付きません。

PNG/SVGの名前にはシード・アルゴリズム版・寸法を含めます。例：`geometry-maker_2d-v4_seed-abcdef_1920x1080.png`。不正なファイル名文字は置換し、シード部分は最大64文字にします。JSON内の元シードは切り詰めません。

SVGは背景、図形のパス・円、グラデーション、発光フィルターを保持したベクターです。アプリのCSSや外部画像・フォントに依存しません。

## 設定JSONの保存・読込

「設定JSONを保存」で現在の設定を保存します。再利用時は「設定JSONを読み込む」でそのファイルを選択します。全項目の検証が完了してから、シード・比率・背景・書き出しサイズを一括復元し、即座にプレビューを更新します。エラー時は現在の設定を変更しません。同じファイルを続けて読み込むこともできます。

```json
{
  "schemaVersion": 1,
  "algorithmVersion": "2d-v4",
  "seed": "abcdef",
  "aspectRatio": "16:9",
  "backgroundMode": "gradient",
  "solidColor": "#111526",
  "gradientColors": ["#101b2d", "#241938", "#102a30"],
  "gradientAngle": 135,
  "exportWidth": 1920,
  "exportHeight": 1080
}
```

ファイル名は例として `geometry-maker_2d-v4_seed-abcdef_settings.json`。JSONは読みやすく整形し、将来の変更用にschemaVersionを含めています。

現在はschemaVersion 1 / algorithmVersion 2d-v4のみ対応します。別版を現在のアルゴリズムで黙って生成せず、未対応版としてエラーを表示します。不正JSON・必須項目不足・不正な色／比率／数値・64KB超のファイルも拒否します。シードは空文字・日本語を含め文字列で、設定ファイルでは4096文字まで対応します。未知の追加項目は取り込まず、既知の設定だけを復元します。

## 既知の制約

- PNGは合計16,777,216画素まで。両辺の上限8192とは別のメモリ制限です。4096×4096や8192×2048まで指定できますが、端末の空きメモリが少ない場合はさらに小さくする必要があります。SVGはこの画素数制限を受けません。
- 書き出しは静止画のみ。編集レイヤー、PSD、3D、動画、アニメーションはありません。
- SVGのnon-scaling-strokeを保持するため、一部の補助線は拡大時もピクセル幅を維持します。発光はSVGフィルターで保持し、外部編集アプリによって表現が異なる場合があります。
- PNG/SVGの比較と再現は同じブラウザで検証しています。異なるブラウザ間のピクセル単位の同一性は未検証です。
- iPhone Safari実機での保存は未検証です。ダウンロードUIが表示された場合は「ファイルに保存」などのブラウザ操作を行ってください。操作ボタンはタッチしやすいサイズにしています。
- 自動保存はありません。設定を残すにはJSONを保存してください。旧版アルゴリズムの自動移行・切替は今回の対象外です。
