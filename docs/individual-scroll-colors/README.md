# 図形ごとの配色と独立した変更周期

「アニメーション」→「無限スクロール」→「スクロールの密度と配色」で設定します。

- **図形色を自動変更**：個々の図形の色を周期的に変化させます。初期ON。
- **図形色変更間隔**：3〜60秒、初期6秒。背景の変更間隔（初期12秒）とは独立です。
- **背景連動カラー生成**：現在の背景から、主役・補助・装飾・アクセントに調和する色を計算します。初期ON。

図形色自動変更をOFFにすると現在の図形色の変化位置を保持します。背景連動ONの場合は、背景変化に応じた視認性・調和の補正を継続します。完全な手動配色にする場合は両方をOFFにします。固定色はどちらの設定でも上書きしません。通常の背景生成の色設定は変更しません。

図形ごとの色は初期シード・チャンクID・図形ID・変更サイクルから決め、近い色相の複数候補を役割別に使い分けます。OKLCHで前後の色を補間します。背景が変わっても図形の色候補は再抽選せず、背景側の補正だけを行います。配置・形状・密度・成長順序は変更しません。

ランダム選択のキャッシュは最大4096件。背景ごとの小さなパレットと同じ補間ペアの結果を共用し、全図形の乱数を毎フレーム引き直す処理は行いません。プレビューと動画は同じ色計算を使用し、PNG/SVGは従来の通常生成の完成静止画を保存します。

JSONの`ambient`内に`scrollFigureAuto`・`scrollFigureInterval`・`scrollFigurePhase`を保存します。旧JSONは初期値を補いますが、背景連動を明示的にOFFにしていた旧設定は手動配色を保つため、図形色の自動変更もOFFで復元します。完全ループでは、両周期をそれぞれループ時間内の整数回数に合わせて境界をつなぎます。

今回の検証は関連ユニットテスト（決定性・独立周期・補間・固定・JSON・v4/v5のSVG色と形状・動画用ワールドとの色一致）、型チェック、本番ビルドに限定しています。目視・実機・長時間動作・画像比較・動画ファイルの実出力テストは実施していません。新しいテーマやプリセットは追加していません。
