# 第3.5段階：2d-v5の多様性と再生成アニメーション

React + TypeScript + Vite / SVGの構成と、背景設定・配色固定・再抽選・密度・PNG/SVG・JSONを維持して拡張しました。追加パッケージはありません。

## 操作

「生成アルゴリズム」はv5が初期値です。シードを変更すると13種類の構図と図形の組み合わせが変わります。成長アニメーションを有効にすると、次の操作で先頭の背景のみの状態から再生します。

- 同じ設定で再生成：構図・図形・色・成長順序は変わらず、再生だけやり直す
- ランダムシード：新しいシードと構図で再生
- 手動シードのEnter確定／入力欄からのフォーカス移動：文字入力中は再スタートせず、確定したときに再生。日本語変換中のEnterは確定として扱わない

再生中の再生成でも古いフレームを取り消し、新しい時計から開始します。色・密度の変更は再生位置を維持します。アニメーション無効時は完成した静止画です。ページを開いたときの自動再生はありません。OSの視覚効果軽減が有効な場合、再生成に伴う自動再生はせず、完成状態を表示します。明示的な再生ボタンは使用できます。

成長時間1〜30秒、0.25〜4倍速、5種イージング、シーク・一時停止は従来どおりです。PNG/SVGは途中停止中でも完成状態を書き出します。

## 追加図形と役割

| 追加図形 | 主な役割と成長 |
| --- | --- |
| 六角形・五角形 | 主役と関連する小多角形。辺をつないで輪郭を描画 |
| 台形・平行四辺形 | 主役や半透明の面・モジュール。輪郭を描きながら面を形成 |
| 星形 | 主役または少数の装飾。中心から拡大し輪郭を形成 |
| 山形・矢印形、ジグザグ | 方向性のある主役・補助・装飾。経路に沿って描画 |
| 放射線群 | 主役または背後のハロー。内側から外側へ時間差で描画 |
| 同心円 | 主役や補助。内側の円から順に円周を描画 |
| 破線フレーム | 主役・モジュール。破線を保持して辺の順に描画 |
| 半円・扇形 | 曲線主体の主役・補助。弧や輪郭を描画 |
| 複合多角形、接続した多角形 | 主役・補助。外形／親の完成後に内部・接続・次の図形を形成 |
| 格子 | 限られた領域の補助・装飾。縦横の線を時間差で伸ばす |
| 枝分かれ回路 | 主役の頂点から伸びる補助構造。幹の途中から枝が伸びる |

共通輪郭を描画・境界・当たり判定に使用します。多角形どうしの内部接続点も実際の辺との交点から求めます。すべての種類を毎回表示する方式ではありません。

[16種類の図形と成長一覧](shape-growth.png)の順序は左上から、六角形・五角形・台形・平行四辺形／星形・山形・ジグザグ・放射線／同心円・破線枠・半円・扇形／複合多角形・格子・枝分かれ回路・接続多角形です。

## 構図と品質

従来の中央集中・斜め流動・コーナー集中・非対称・フレームに、放射・同心円・螺旋・モジュール・複数アンカー・曲線・水平垂直・多角形を追加しました。同じ型でも位置・主方向・主役の種類・大きさ・モジュール・成長時刻が変わります。

構図を先に作り、1〜2個の主役と関連する図形ファミリーを配置します。曲線系は周回・螺旋、モジュール系は限られたセル群、軸系は水平垂直の流れを使います。既存の連続ノイズも補助の大きさへ使用します。主役の実際の輪郭を検査してタイトル用の空白候補を選び、その余白と交差する補助候補を採用しません。小装飾どうしの近接、塗りつぶし主役との重なり、意図しない画面外への切断も除外します。背景の薄い面、主役、限られた発光の3層は維持しています。

最大密度の候補にID・グループ・親・重要度・開始密度を付け、密度では表示だけを変えます。0%は背景のみ、50%は標準、100%は追加候補を表示。開始密度は親以上で、接続線だけが孤立しません。最大128図形と有限の試行回数で負荷を制限します。候補とスケジュールはシード・比率・版が変わったときだけ作り、フレームごとの乱数は使いません。

## バージョンと互換性

`algorithmVersion: 2d-v5`と成長の`growth-v2`を使用します。旧`2d-v4`は旧生成コード・密度候補・`growth-v1`を維持して復元します。v4のJSONを読むと「旧v4設定を読み込み、元の構図を保持」と表示し、生成アルゴリズム欄もv4になります。v5への切替はユーザーの明示操作です。JSON再保存とPNG/SVGのファイル名にも現在の版を使います。v4以前の未対応版はエラーにし、黙って置き換えません。

変更前のmain `1087d6401d44534aac444f05814899346979808c`のビルドと新版に同じv4 JSONを読み込み、6シード×3比率×密度50/100の36条件で、完成画像の画素が完全一致することを確認しました。[画素ハッシュ記録](legacy-validation.json)。

## 検証

- 型チェック、ユニット109件、ブラウザ16件、ビルドを実行
- v4固定ダイジェストと全8比率×100シードの既存品質テストを維持
- v5は24シード×全8比率で再現性、ID、空白、境界、親子、密度0/25/50/75/100、親の成長完了後の子の開始を検証。追加100シードでも決定性と上限を確認
- 全16図形の輪郭・衝突・成長、5種類のイージング、再生速度・時間を検証
- 模擬時計で再生中の再生成を繰り返し、シークした同じ時刻で同じSVG、完成時は元の静止画と一致することを確認
- 手動入力途中は再スタートせず、Enter・フォーカス移動・ランダムで先頭再生。色・密度は再生位置を維持
- 配色固定・再抽選、PNG/SVGとプレビューの画素一致、途中停止時の完成PNG、旧新版JSONの復元、スマホ幅・タッチを回帰検証

生成コストは100シードのローカル測定で中央値約13ms、95パーセンタイル約56msでした（実行環境依存、描画を含まない参考値）。アニメーション中はSVG定義と輪郭をキャッシュし、再生開始時刻と絶対経過時間から進行率を求めるよう修正し、フレームの欠落や状態更新の遅延で成長時間がずれないようにしています。OS・ブラウザ間の画素一致や実機iPhone Safariの性能は保証する測定をしていません。スマホはChromiumのタッチエミュレーションで確認しています。

## 再実行

`npm run dev`を起動し、`npm run typecheck`、`npm test`、`npm run build`、`CHROMIUM_PATH=/usr/bin/chromium npm run test:browser`を実行します。Chromiumパスは環境に合わせて変更できます。全ブラウザテストの新図形一覧ページは開発専用で、本番ビルドへ含めません。

比較画像の作成は`CHROMIUM_PATH=/usr/bin/chromium node scripts/capture-diversity.mjs`。変更前ビルドを別途ポート4173で配信してください。`BASELINE_URL`と`PREVIEW_URL`で接続先を変更できます。

3D・動画・Blender・PSD・待機画面は追加していません。
