## 変更前後

変更前は、同程度の大きさの図形76個を独立に配置していました。変更後は、構図を先に決めてから主役・補助・装飾を配置します。

| 観点 | 2d-v1 | 2d-v2 |
| --- | --- | --- |
| 配置の基準 | 図形ごとの乱数 | 主方向・密集域・余白・主役候補を持つ構図計画 |
| 主方向 | 図形ごとに個別 | 1枚につき0°・45°・90°・135°のいずれか |
| 空間の特徴 | おおむね一様 | シード付きの滑らかな2周波数ノイズ、密集域、方向に沿う密度変化 |
| 役割 | 明示なし | 主役5・補助27・装飾44、役割ごとの配色・線幅・透明度 |
| 主役 | サイズ差が小さい | 大きな枠・円弧・三角形・帯、種類の配置順もシード依存 |
| 補助 | 独立した図形 | 主方向の線・長方形、主役の頂点に接続する回路線 |
| 装飾 | 点や小図形が散在 | ドット群・十字・アクセント三角群、主役の周囲を優先 |
| 余白 | 保証なし | 中央の幅30%×高さ30%（画面面積の9%）を保護し、周辺を徐々に疎にする |
| 重なり | 制限なし | 保守的な形状半径で間隔を確保。記録された親子接続のみ意図的に許容 |

主役の大きさ・線幅・発光幅は短辺に基づき、位置と余白は比率ごとの画面座標で計算します。横長を縦長に引き伸ばす方式ではありません。図形データの上限を76グループに維持し、配置探索にも上限を設けています。

## 実装範囲

- `src/scene.ts`: 構図計画、空間ノイズ、密度マップ、間隔・余白制約、3層生成、アルゴリズム版 `2d-v2`。
- `src/Preview.tsx`: 新しい図形データをSVGとして描く最小限の拡張。円弧、帯、枠、ドット群、十字、主役の淡いグラデーション・発光を追加。
- Reactの操作画面、CSS、シード入力・ランダムボタン、背景設定、全8比率は変更なし。
- 生成処理と描画処理の分離を維持。製品の保存機能・アニメーション・3Dなどは追加していません。

v1とv2は同じシードでも結果が変わります。v1はmain/コミット `196b1779db3eec5227dffc3b1681fa87bca347ef` に保存されています。この候補版に旧アルゴリズムの選択UIは追加していません。

## テスト結果

- `npm test`: **29件成功**。既存18件を維持し、構図の検証11件を追加。
- 追加テストで全8比率×100シード = **800構図**を検証。役割数、有限座標、画面内配置、中央余白、方向、意図しない重なりの制限を確認。
- 同じシード・比率の再生成、空文字・日本語・絵文字、前後空白・先頭ゼロの区別を引き続き検証。
- 空間ノイズの格子境界をまたぐ連続性、複数シードでの構図・方向・主役順の差、v2の固定ダイジェストを検証。
- `npm run build`: **型チェック・本番ビルド成功**。
- `npm run test:browser`（Chromium）: **2件成功**。既存操作・背景切替・再入力・再生成・リロードの画像一致、全8比率、幅1440/1024/390pxでの表示、3層の描画を確認。
- 追加の1,200構図生成（150シード×8比率）: 例外なし。主役のサイズは最小で短辺の12.5%、主役の平均サイズは補助の平均サイズの少なくとも1.87倍。親子接続は各構図5〜7本。これらは検証したサンプルでの値です。
- 代表12構図の新旧撮影と中央占有率の検証に成功（新旧で計24画像）。

正方形の一部シードで主役の配置候補が不足する問題を開発中に検出し、5番目の主役候補と探索範囲を修正しました。また、Reactが図形間でSVG要素を再利用すると、同じ属性でも挿入順だけが変わることがあるため、ブラウザテストのDOM比較を属性順・内部IDに依存しない比較に変更しました。描画画像の一致確認は維持しています。最終候補のテストに失敗・スキップはありません。iPhone Safari実機の検証は今回実施していません。

## 比較の再作成

`npm run dev` を別ターミナルで起動し、次を実行してください。製品への画像書き出し機能追加ではなく、開発用の撮影スクリプトです。

```sh
CHROMIUM_PATH=/usr/bin/chromium node scripts/capture-composition.mjs
```

環境に応じて `CHROMIUM_PATH` を変更・省略できます。`BASELINE_URL` と `PREVIEW_URL` で比較元・比較先を指定できます。既定の比較元は公開Pagesで、比較先はlocalhostです。比較元が2d-v1、比較先が2d-v2でなければ停止します。将来mainが更新された後は、旧コミットをローカルで起動して比較元URLを指定してください。
