# 放射線の枝装飾分散

12本の放射線を複数の輪郭として返していた一方、装飾生成では最初の輪郭（1本分の2端点）だけを参照していました。

放射線の主役に対し、全12輪郭からシード付きの開始方向を選び、回路は60度ずつ離れた6方向を候補にします。小装飾は対向方向を含む順序で12方向を巡回し、1方向につき採用上限4個とします。枝の長さ、装飾の種類・位置・出現密度には決定的なばらつきを残します。中心寄りの放射線上にも候補を配置し、画面外・予約した余白・過密な小装飾の除外は維持します。装飾のために余白を埋める処理は追加しません。

比較：seed `ray-49`、16:9、密度100%、発光100%。

- [変更後](after.png)

この例では異なる4方向の回路が採用され、小装飾も複数の放射線へ分散します。型チェック・ビルド・ユニット113件を確認。追加テストは400シード×16:9/9:16/1:1から放射線の主役を持つケースを調べ、回路が2方向以上・小装飾が4方向以上、枝位置重複なし・完全再現を確認します。既存の密度・アニメーション・書き出しテストも維持します。
