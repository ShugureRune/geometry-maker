# ワールド密度に従う無限スクロール配置（v3）

チャンクは管理・キャッシュ・削除の単位です。図形群を各チャンク中央へ1つずつ置く方式は廃止しました。

- ワールド座標の連続ノイズを2つのスケールで合成し、密度の高低を作ります。
- 管理チャンクとは別の特徴点セルからクラスタを決定し、大きな主役の周辺へ小さな図形群を配置します。クラスタの各グループは独自の中心・半径・回転・シードを持ちます。
- 1つの管理チャンクには0〜複数のグループが入り、主役がない装飾のみの小集団も存在します。グループは境界でクリップしません。
- 近隣候補の半径と固定優先順位で競合を解決します。全近隣候補を参照するため、生成・読み込み順で配置は変わりません。
- 図形群のアンカーが画面に入った時刻から、各グループが独立して成長します。親子関係と既存の成長エンジンを再利用します。

通常2Dのv4/v5生成器は変更していません。スクロール専用密度、個別配色、独立した色周期、背景自動変更、発光、JSONの設定項目も維持します。同じ保存設定でも無限変化スクロールの配置は新方式になります。完全ループの有限配置方式は従来どおりです。

管理チャンクは最大48件、完全な図形データは画面付近のみ遅延生成して最大48グループ、密度場の特徴点セルは最大96件に制限します。空チャンクではSVG図形を生成せず、既存グループは毎フレーム再生成しません。配色用キャッシュも従来の上限を維持します。

PNG/SVGは従来の通常生成の完成静止画です。MP4/WebMはプレビューと共通のワールド配置・進入時刻・色計算を使います。

## 軽量検証

関連ユニットテストで、空／複数グループのチャンク、中心固定の解消、連続密度、可変半径による重なり抑制、生成順序の独立性、境界をまたぐ範囲、キャッシュ解放と再生成、v4/v5の密度変更時の形状維持、グループ別の進入時刻、動画用ワールドとのSVG配色一致を確認しています。

型チェック・本番ビルドも実施します。大量の画像比較、長時間のブラウザ操作、実機確認、動画ファイルの実出力は今回は実施していません。
