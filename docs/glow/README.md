# 暗色テーマと発光

配色の生成欄に「ミッドナイト」「ネオンナイト」と「発光強度」を追加しました。テーマは固定されていない色だけへ適用し、手動／シード連動モード・固定・再抽選回数は維持します。背景モードも維持するので単色・グラデーションの両方で使えます。固定した背景色が明るい場合、その色を暗色へ置き換えません。

発光は0〜100%（5%刻み）、初期値0%。0%では発光フィルターを出力しません。主役・アクセントを強め、補助45%、装飾28%の重みを使います。明るい背景では発光を22%に抑えます。強度に応じてぼかしと光量を増やし、暗い背景では輪郭の不透明度も少し補います。色のHEX値は変更せず、ぼかしたコピーの上に明瞭な元の図形を残します。塗り面全体を光らせず、輪郭とドットを中心に描画します。

配置・シード・密度・成長順序は変わりません。強度変更で再生位置は戻りません。アニメーションの成長状態を発光コピーにも適用します。PNG/SVGは発光を含む完成状態を保存します。設定JSONには`glowIntensity`を保存し、旧JSONで省略されている場合は0%として復元します。範囲外・整数以外は読込エラーです。

## 検証

型チェック・ビルド、ユニット112件、ブラウザ17件が成功。明暗背景の0/25/50/75/100%を実際にレンダリングし、配置と固定色の維持、アニメーション途中、スマホ幅を確認しました。明暗両方で発光100%のPNGとSVGを実保存して画素一致を確認し、発光75%での設定JSON復元・再保存とPNG再現性も既存書き出しテストで検証しています。
