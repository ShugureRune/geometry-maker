# 無限生成スクロールとスマホ用スライダー

## 操作

「アニメーション」→「自動待機画面を有効化」→「無限スクロール」を選びます。

- **無限変化**：基本シードとチャンク座標から新しい模様を生成し続けます。通常のシード入力は保持します。
- **完全ループ**：既存の有限パターンを周期再生します。無限変化とは別方式です。
- 「待機画面の詳細設定」で速度・方向などを変更できます。数値10項目はすべてスライダーで、現在値と単位を表示します。
- 一時停止は移動と成長を同時に停止。停止は先頭に戻します。
- 無限変化スクロールでは自動シード更新・更新間隔を使用せず、座標ごとの生成を優先します。ループ時間は移動速度の基準として使用し、カメラ位置は周期で戻りません。

## 生成・成長

`scroll-world-v1`のシードは`基本シード::scroll-world-v1:x:y`です。v4/v5の生成器と密度候補、親子関係、成長スケジュールを再利用します。同じ座標へ戻ると、キャッシュから削除済みでも同じ模様を復元します。

カメラは連続するワールド座標を移動します。速度・方向変更時には、その時点の位置から新しい移動区間を開始するため位置が飛びません。区間の履歴は実行中の動画書き出しにも渡します。保存JSONは従来どおり設定値を保存し、読込後はその設定から新しい再生を開始します。

各模様の主役中心をワールド上のアンカーとして配置し、アンカーと表示領域の最初の交差時刻を解析的に求めます。その時刻までは非表示、その後は経過時間から成長を描画します。すでに進入済みの模様は再成長しません。高速スクロールでは、完成する前に画面外へ移動する場合があります。

背景は1枚の共通グラデーション／単色で描画します。模様は反転・複製せず、配置を揺らし、グループの実際の境界から大きさを決めます。チャンクごとの矩形クリッピングを避け、背景の格子状の継ぎ目や枝の切断を抑えています。色は現在の指定色を共通利用し、固定色を維持します。

## 性能・書き出し

- 画面と周囲1チャンクを先読み。画面から離れたSVGは描画対象から削除します。
- レンダラーごとのLRUキャッシュは最大48チャンク。毎フレームの再生成は行いません。
- 非表示タブの休止、20fpsの低負荷設定、視覚効果軽減は既存方式を維持します。
- MP4/WebMも同じチャンク生成器・進入判定・時刻指定描画を使います。出力時のキャッシュも最大48件です。
- PNG/SVGは従来どおり通常生成の完成静止画を保存します。
- 動画の対応形式・解像度・長さ上限は既存のブラウザ制約に従います。

## 検証

- 型チェック、ユニットテスト131件、ビルド。
- v4/v5 × 横・縦・斜め × 16:9・9:16・1:1で、背景のみ→成長→退出、新規シード、座標再現、キャッシュ上限を確認。
- 同時刻のプレビューと動画SVGの輪郭を比較し、0/1/3/10秒のレンダリング画像の平均RGB差が1未満であることを確認。
- WebM/MP4を実際に書き出し、ffprobeでフレーム数を確認。
- スマホ幅で全10スライダー、JSON復元、停止中の速度・方向変更による位置保持を確認。
- WebKitのiPhone相当環境、ChromiumのAndroid相当環境で全スライダーをタッチ操作。実機iPhone/Androidでの確認ではありません。
- 完全ループと既存のPNG/SVG/JSON・動画・カラー固定・密度・成長のブラウザ回帰テスト。
