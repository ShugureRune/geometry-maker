# シード連動配色・個別再抽選・固定

開発ブランチ `feat/seeded-color-locks`。mainとPages本番は未変更です。構図のアルゴリズムは2d-v4のまま、色には独立したcolors-v1系列と配色設定version 1を使用します。

## 操作

初期状態は「シードに連動」、明暗は「シードで決定」です。「手動色を維持」は従来の背景と図形配色を維持します。「カラー変更モード」を「シードに連動」にすると、固定していない色がシード変更に連動します。自動配色の明暗はシード・明るい背景向け・暗い背景向けから選べます。

7スロット：単色背景、グラデーション3色、主役、補助、アクセント。背景種類に応じて対応する背景スロットを表示します。各行でピッカーまたは#RRGGBBを編集、🎲でその色だけ再抽選、🔒で固定を切り替えます。無効なHEXの途中入力は描画に渡さず、フォーカスを外すと確定色に戻します。

固定ONでも手動編集・再抽選が可能で、新しい確定色を固定したまま維持します。固定OFFの手動色は、シード連動モードで次のシード変更時に再生成されます。手動モードではシードを変えてもすべての入力色を維持します。手動指定色をコントラスト補正で別のHEXへ書き換えません。必要な視認性は自動配色の明暗選択か手動編集で調整してください。

色を変えてもシード・比率・図形の位置や形状は変えません。背景と図形の色は共通の調和色相を参考にしながら、背景／図形の明度・彩度に別のルールを使用します。各スロットの再抽選は `seed + slot ID + reroll` による別々のPRNGです。図形のPRNG状態へ書き込みません。

## 設定と互換性

従来の設定JSON（schemaVersion 1）に任意の `colorSettings` を追加しました。既存ファイルはそのまま読込可能です。配色情報がなければ手動モードで従来の描画を復元し、勝手にシード配色へ変換しません。

`colorSettings` はversion、mode、appearance、各スロットのcolor／locked／reroll、および手動で確定した図形色のスロットID（edited）を保存します。固定中の色はカラーコードとして保存。保存時点の全確定値とカウンターを復元するため、再読込後の再抽選も継続できます。配色設定が不正なら設定全体の読込を拒否し、現在の設定は変更しません。

既存のalgorithmVersion、シード、比率、背景モード、角度、書き出し解像度も引き続き保存します。PNG・SVGは表示中のSVGから出力するため、その時点の色が含まれます。旧アルゴリズム版を黙って現在版で生成することは引き続き行いません。

## 確認

ユニットでは同一シードの一致、対象以外のスロット不変、固定色の維持、再抽選カウンターの復元、手動モードの不変性を検証。ブラウザでは固定・再抽選・HEX・シード変更・グラデーション各色・配置不変・JSON保存読込・SVG内の設定色・PNGダウンロードを確認しています。既存のPNG/SVG/プレビューの画素一致、旧JSON復元、全比率、スマホ操作の回帰テストも維持しています。スマホ色操作はChromiumのタッチ設定で確認し、iPhone Safari実機は未確認です。

追加パッケージ・バックエンド・CDN・3D・アニメーション・動画機能はありません。起動は従来どおり `npm ci` → `npm run dev`、検証は `npm test`、`npm run build`、開発サーバー起動後の `npm run test:browser` です。
